## 재검토 후 테스트 재개

1. 정책 지원팀의 비의료 분류/건강 선언 적용 범위 답변을 확인합니다. 비의료 범위로 개인 계정 배포가 허용되면 정확한 선언으로 수정하고 저장된 스토어 설명/비공개 버전을 재제출합니다. 조직 계정이 계속 필요하다는 답변이면 조직 인증 또는 실제 기능 범위 변경을 검토합니다. 이름/설명만 바꿨다고 요건이 자동 해제되지 않습니다.
2. Google 승인·비공개 버전 게시 후 참여 링크 활성 여부를 확인합니다. 현재 [웹 참여 주소](https://play.google.com/apps/testing/kr.safekor.app)는 사용할 수 있다고 보장하지 않습니다. Android 설치 주소는 https://play.google.com/store/apps/details?id=kr.safekor.app 입니다.
3. 직접 모집 방식: [Alpha 테스터 관리](https://play.google.com/console/u/3/developers/7181631274097055190/app/4974887941231472773/tracks/4699249421656772828?tab=testers) → `safeKor 비공개 테스트` 수정 → Google 계정 이메일 추가·저장. 목록 등록과 실제 참여 동의는 다릅니다. CSV는 기존 주소를 덮어쓸 수 있습니다.
4. Tester Match 방식: 현재 등록 화면의 이름/두 링크/설명만 입력했고 **최종 등록하지 않았습니다**. 사이트는 등록 즉시 매칭을 시작하므로 승인·게시 전 매칭을 시작하지 않습니다. 사이트 필수 안내인 `tester-match@googlegroups.com` 공용 그룹 접근 허용도 아직 설정하지 않았습니다. 개인 이메일 목록과 Google 그룹 선택 전환을 대조한 뒤 변경해야 합니다. 사용자의 그룹 가입/맞테스트 수행/메시지 발송도 대행하지 않았습니다.
5. 이미 내부 테스트에 참여한 계정은 내부 참여 페이지에서 내부 테스트 중지 후 비공개 테스트 참여를 선택해야 합니다. 12명 이상이 연속14일 참여 상태를 유지하며 실제 기능을 사용하고 피드백/수정 사항을 기록합니다. 경과만으로 자동 승인/출시되지 않습니다.

## 후속 카테고리 변경

사용자의 다른 카테고리 선택 요청으로 스토어 설정을 **도구 → 지도/내비게이션**으로 변경해 저장했습니다. GPS 주변 대피소 탐색·지도 표시라는 실제 기능에 근거합니다. 콘솔 저장 완료 메시지와 게시 개요의 `앱 카테고리(지도/내비게이션 앱) 선택` 항목을 확인했습니다. 재심사 전송은 하지 않았고, 게시 개요에는 기존 거부 및 검토 전송 전14개 변경사항이 남아 있습니다.

건강 기능 신고는 별도이며 이번 스토어 분류 변경에서 수정하지 않았습니다. 조직 계정 거부 해소·Google 승인·비공개 게시 완료로 간주하지 않습니다. Tester Match도 최종 등록하지 않았습니다.

비교 대상으로 요청한 Trova는 해당 콘솔의 정책 상태 `발견된 문제 없음`, 최근 게시일2026-10-27을 읽기 전용으로 확인했습니다. 건강 기능 신고 내용은 아직 대조하지 않았으므로 설정을 복제했다고 보고하지 않습니다. Trova의 설정은 변경하지 않았습니다.
