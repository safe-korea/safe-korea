## 콘솔 진행 상태

내부 테스트 트랙의 비활성/초기 설정0/3 상태와 테스터 목록 부재를 직접 확인했습니다. 릴리스 준비 페이지를 열고 이름·노트를 입력했지만, 파일 창 자동 확인이 적용되지 않아 업로드/초안 저장/게시 완료를 확인하지 못했습니다. 조작이 방해된다는 사용자 지적 후 자동 포커스 조작을 멈추고 에이전트가 만든 업로드 탭만 닫았습니다. 기존 콘솔 탭은 보존했습니다.

테스터 Google 계정1명을 사용자에게 받았으나 아직 목록에 등록하지 않았습니다. 계정 주소는 이 공개 문서에 기록하지 않습니다. 초대 메일이나 외부 메시지는 발송하지 않았습니다.

새 분리 Chrome은 제어 연결 자체는 됐지만 Google 로그인 거부 화면으로 이동해 닫았습니다. 로그인 차단을 우회하지 않습니다. Google 공식 Chrome DevTools MCP를 로컬에 준비하고 사용 통계/CrUX 전송을 끈 설정의 초기화·도구 메타데이터를 확인했습니다. 기존 Chrome의 원격 디버깅 허용은 사용자 승인 후 브라우저 자체 설정/연결 허용을 진행하며, 실제 연결 전에는 탭 내용을 읽거나 설정 완료로 보고하지 않습니다.

## 연결 후 수행할 순서

1. 기존 내부 테스트 준비/라이브러리 상태를 확인하여 versionCode2의 업로드 여부를 먼저 확인합니다. 이미 사용된 코드면 재사용하지 않습니다.
2. 해시를 고정한 제출 후보를 업로드하고 Play 처리/오류를 확인합니다.
3. 한국어 릴리스 노트와 이름을 저장하고 검토 화면으로 진행합니다.
4. 승인받은 테스터1명 목록을 만들어 내부 트랙에 지정합니다. 임의의 추가 사용자나 공개 그룹은 포함하지 않습니다.
5. 콘솔의 차단 조건을 실제 화면 기준으로 해결하고 내부 테스트 배포/참여 링크를 확인합니다. Google 계정 확인/본인 인증·플랫폼 권한 승인은 사용자가 직접 수행합니다.
6. Play 설치본의 실제 서명으로 Kakao 인증·핀/GPS·오프라인·알림을 검증합니다. 내부 테스트 참여와 신규 개인 계정의 프로덕션용 비공개 테스트 요건은 구분합니다.
