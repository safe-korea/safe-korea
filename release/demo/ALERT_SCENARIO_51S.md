# 경보를 들은 순간부터 — 최신 51초 시연

`artifacts/demo/safeKor_경보상황_스토리시연_자막음성.mp4`, 1080×1920 H.264/AAC. 이전 훈련 메뉴 시연을 대체하는 새 편집본이며 기존 영상은 보존합니다.

| 시간 | 이야기 |
|---|---|
| 0–5초 | 붉은 ‘공습경보’ 상황 카드와 짧은 사이렌. 경보를 들은 상황 재현 표시 |
| 5–8초 | 앱 열기 → 지금 할 행동 보기 |
| 8–14초 | 들은 경보 종류를 사용자가 선택 |
| 14–21초 | 실내 선택 → 계단으로 이동, 물품 찾느라 지체하지 않기 |
| 21–26초 | 사전에 저장한 공식 대피소 확인 |
| 26–35초 | 통신이 끊긴 상태에서 저장한 도로 지도와 확대 화면 확인 |
| 35–40초 | 통신 복구 후 시연용 가족 만남 장소 확인 |
| 40–47초 | 공유 내용 확인 → 실제 OS 공유 창. 메시지 발송 없음 |
| 47–51초 | 확정 진돗개 아이콘과 ‘미리 준비해 두세요’ 마무리 |

실제 정부 경보를 수신한 촬영이나 구현되지 않은 푸시 UI가 아닙니다. 첫 장면은 편집용 상황 카드이며 앱 화면으로 표시하지 않습니다. 이후 실제 앱의 일반 행동 안내를 사용하며 훈련 모드에는 들어가지 않습니다. 영상 안에 상황 재현 표시를 유지합니다. 가족/지도 부분은 같은 최신 코드로 검증한 기존 촬영을 사용하고 지도 화면은 다음 장면이 섞이지 않도록 검증된 네이티브 캡처를 유지합니다. 현재 위치·경로·개방 여부를 보장하지 않습니다.

`integration_test/alert_scenario_demo_test.dart`에서 일반 홈의 ‘지금 할 행동 보기’ → 공습 선택 → 실내 선택·계단 안내를 실제 조작하여 검증했습니다. `scripts/edit_product_demo.py --scenario`로 한국어 자막·로컬 Yuna 음성·1.5초 낮은 음량 사이렌을 합칩니다. SRT와 편집 타임라인을 별도 제공합니다.
