# safeKor 53초 전체 시연

2026-11-02 최신 코드로 실제 iPhone 17 Pro 네이티브 개발 앱을 촬영했습니다. Android 출시 앱 기능을 설명하는 개발 시연이며 iPhone PWA와 기능 범위가 같다고 설명하지 않습니다.

## 영상·음성

- `artifacts/demo/safeKor_전체시연_자막음성_60초이내.mp4`: 1080×1920, H.264/AAC, 53초.
- 동일 파일을 사용자 Mac 바탕화면에 복사. 기존 약 30초 지도 영상은 보존.
- 자막은 화면 바깥 하단에 배치해 버튼·행동 안내를 가리지 않음. SRT도 별도 제공.
- 로컬 macOS Yuna 합성 음성 사용. 외부 TTS 서버에 자료 전송하지 않음. 기존 훈련용 사이렌 파일을 경보 구간 처음 1.5초에 낮은 음량으로 삽입. 실제 정부 수신 시연 아님.
- 공식 시설 스냅샷의 잠실역 시설 한 곳을 UI로 저장하고 공개 서버에서 주변 도로 자료 다운로드. 전용 SQLite에서 재로딩 후 신규 HTTP 연결을 차단한 상태로 지도 열기·확대.
- 가족 약속은 전용 SQLite의 시연용 자료이며 기존 가족 기록 변경 없음. 통신 복구 후 공유로 구분. 메신저 수신자 선택/전송 없음.

## 재현

`integration_test/full_product_demo_test.dart`와 `family_product_demo_test.dart`로 실화면을 촬영. `scripts/edit_product_demo.py`가 장면별 클립·한국어 자막·로컬 음성을 합침. 원본 녹화는 변경 없는 화면에서 프레임이 드문 VFR이므로 CFR 변환 후 편집해야 함. 현재 캡처 마커는 artifacts/demo/*-markers.json, 편집 타임라인은 full-demo-timeline.json.
