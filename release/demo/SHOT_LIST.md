# safeKor 90초 시연 촬영안

2026-11-02 작성. Android 네이티브 출시 기능 기준이며 iPhone 17 Pro 네이티브 시뮬레이터는 개발 시연용입니다. 배포된 iPhone PWA의 기능 범위와 같다고 설명하지 않습니다.

| 초 | 조작 | 자막 |
|---|---|---|
| 0–8 | 아이콘 → 홈 | 갑작스러운 경보, 무엇부터 해야 할까요? |
| 8–20 | 모의 공습 훈련 실행 → 빨간 행동 화면 | 지금 해야 할 행동부터 크게. |
| 20–35 | 실내 선택 → 첫 행동 안내 | 내가 있는 상황에 맞게 바로 행동하세요. |
| 35–48 | 잠실 지역 조회 → 미리 저장한 공식 시설 | 대피소를 미리 확인하고 저장하세요. |
| 48–65 | 오프라인 기능 → 저장한 대피소 → 보관한 약도 확대 | 연결이 끊겨도, 미리 준비한 정보는 남습니다. |
| 65–80 | ‘통신 복구 후’ 자막 → 가족 만남 장소 → 가족에게 공유 → 내용 확인 | 연락이 될 때, 만날 장소를 먼저 공유하세요. |
| 80–90 | 아이콘·진돗개 | 미리 준비해 두세요. 필요할 때 바로 행동할 수 있도록. |

## 촬영 전

- 시뮬레이터 위치: 잠실역 주변 37.5133, 127.1001. 모의 위치이며 실제 GPS 측정 아님.
- 공식 조회로 저장한 시설을 사용합니다. QA용 가짜 시설·이미지를 실제 대피소처럼 촬영하지 않습니다.
- 약도는 해당 시설과 일치하고 저장 권한을 확인한 자료만 준비합니다. 출처·범례를 잘라내지 않습니다. 개발 앱은 최대 1280px로 변환하므로 작은 글씨가 읽히는지 확인하세요.
- 저장한 대피소 → 내 기록 · 선택 → 사진 관리 → 오프라인 약도 이미지 추가 → 출처 → 이미지 → 기기에 저장. 저장 목록에서 ‘저장한 약도 크게 보기’가 나타나는지 확인합니다.
- 가족 장소·약속은 시연용으로 준비하고 개인정보를 노출하지 않습니다. 기존 사용자 계획을 임의로 덮어쓰지 않습니다.
- 장면별로 나누어 촬영하고 각 핵심 화면을 3–5초 유지합니다. 설명 자막은 한 장면에 한 문장.

## 경보 장면

모의 경보/훈련 표시를 유지합니다. 소리가 필요하면 테스트 알림 설정에서 사용자가 사이렌을 켠 뒤 실행합니다. 공개 영상 시작에 ‘모의 경보·사이렌이 포함된 시연’ 표시. 실제 정부 수신이나 자동 원격 알림 시연이 아닙니다. 화면 녹화에 소리가 포함되는지는 별도 확인합니다.

## 오프라인 장면

실기기는 준비 자료 저장 후 비행기 모드와 Wi-Fi 해제를 확인합니다. 앱을 다시 열어 행동요령·주소·약도·가족 약속이 남는지 확인합니다. 이미 읽던 행동요령은 네트워크 상태 변경으로 닫히지 않아야 합니다.

시뮬레이터 상태 표시줄의 Wi-Fi 아이콘을 숨기는 것은 실제 통신 차단이 아닙니다. 자동 테스트는 연결 상태를 주입하며 이 경우 ‘통신 끊김 상황 재현’으로 표시합니다. Mac 전체 네트워크를 촬영 목적으로 임의 차단하지 않습니다. 수동 ‘오프라인 기능 모아보기’ 화면은 저장 정보 소개에 사용할 수 있지만 실제 단절 감지를 입증하지 않습니다.

약도는 저장한 정지 이미지입니다. 현재 GPS 점·경로·최신 현장 상태가 표시되지 않습니다. 온라인 지도 배경이 오프라인에서도 된다고 설명하지 않습니다.

## 가족 공유 장면

‘평소 준비’ 또는 ‘통신 복구 후’로 구분합니다. 공유 미리보기 → OS 공유 창까지만 시뮬레이터에서 촬영할 수 있습니다. 카카오톡 전송·도착은 앱이 설치된 실물 휴대폰에서 동의한 시연 상대와 확인합니다. 공유 창을 여는 것만으로 발송 완료 자막을 넣지 않습니다.

## 녹화

```sh
xcrun simctl io E3A83EF7-8FD6-4656-AE84-EFA2E3136351 recordVideo /private/tmp/safeKor-demo.mov
# 장면 종료 후 Ctrl+C. 원본을 검토하고 편집합니다.
```

시뮬레이터 영상은 네이티브 개발 앱 시연입니다. Android 광고·스토어에는 실제 Android 화면을 별도로 촬영하고, iPhone PWA 광고에는 현재 PWA에서 제공하는 기능만 사용합니다.
