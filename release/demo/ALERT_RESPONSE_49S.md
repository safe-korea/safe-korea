# 경보 대응 화면 — 최종 49초 시연

최종 파일: `artifacts/demo/safeKor_경보상황_최종시연_49초.mp4`.
바탕화면에도 같은 파일을 복사했습니다. 1080×1920 H.264/AAC, 영상과 오디오 모두 49초입니다.

| 시간 | 장면 |
|---|---|
| 0–5초 | 공습경보 상황 재현 카드, 짧은 사이렌 |
| 5–12초 | 합성 경보를 공통 수신부에 입력 → 실제 대응 화면 자동 전환 |
| 12–19초 | 실내 선택 → 계단으로 이동. 물품 찾느라 지체하지 않기 |
| 19–24초 | 미리 저장한 시설 확인, 신규 네트워크 차단 |
| 24–33초 | 저장한 도로 지도 열기·확대 |
| 33–38초 | 통신 복구 후 시연용 가족 만남 약속 |
| 38–45초 | 공유 내용 확인 → 실제 OS 공유 창. 발송 없음 |
| 45–49초 | 진돗개 아이콘, “위급한 순간, 첫 행동을 함께합니다. safeKor.” |

훈련 메뉴/홈의 훈련 버튼을 촬영하지 않습니다. 실제 정부 발송을 촬영한 것은 아니며 영상 내 상황 재현·합성 입력을 표시합니다. 대응 화면은 `integration_test/civil_alert_response_demo_test.dart`에서 수신부에 명시적 합성 이벤트를 넣어 자동 전환을 확인한 실제 앱 화면입니다. iPhone 네이티브 개발용 시뮬레이터 촬영이며 PWA의 정부 푸시 완료를 뜻하지 않습니다.

최종 홀드 장면의 simctl 녹화 프레임 생략을 피하기 위해 실내 안내는 같은 테스트에서 저장한 네이티브 캡처를 사용합니다. 지도·가족 공유도 검증된 실제 앱 촬영/캡처입니다. 애니메이션 전체가 실시간 연속 녹화라는 주장은 하지 않습니다.

자막은 SRT와 `scenario-demo-timeline.json`에 별도 제공하며 로컬 Yuna 음성을 사용합니다. 음성·사이렌은 PCM 샘플 위치를 지정해 합성하여 마지막 문장이 잘리지 않도록 영상과 음성을 모두 49초로 맞췄습니다. 인코딩 후 최대 음량은 -4.8 dBFS입니다. 예전 51/48초 파일은 작업 이력이며 최신본은 이 49초 파일입니다.
