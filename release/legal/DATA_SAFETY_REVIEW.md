# Google Play 데이터 보안 신고 — Android 1.0.0(2)

2026-11-03 확인. 운영자 safeKor / 문의 taetaeg@gmail.com. 대상은 Google Play의 `kr.safekor.app` 네이티브 Android 배포본이며 iPhone PWA를 혼합하지 않습니다. **콘솔의 최종 저장/검토 상태는 `release/store/play-registration.json` 참조.** 이전 2/5단계 임시저장 초안을 실제 구현과 SDK 확인 근거로 구체화했습니다.

## 신고 결정

- 전체 수집/공유: 예. Android 계정 생성·외부 계정 로그인: 없음. 광고 목적·계정 관리·맞춤광고는 선택하지 않습니다.
- 전송 암호화: 예. 아래 API/타일/SDK HTTPS 근거에 따른 판정이며 별도 독립 보안 인증을 주장하지 않습니다.
- 삭제 요청 선택 문항: 아니요. 기기 자료 삭제와 문의 정보 삭제 방법은 제공하지만 운영자가 지도/호스팅 사업자의 모든 네트워크 기록을 조회·삭제하는 통합 기능은 없습니다. ‘모든 자료90일 이내 자동 삭제’도 선택하지 않습니다.
- 필수 표시는 온라인 실행 시 자동 연결 확인과 네트워크 처리에 따른 IP·기술 요청 정보까지 포함합니다. GPS 사용이 강제되거나 오프라인 행동요령에 네트워크가 필요하다는 뜻이 아닙니다. 정확한 현재 위치 지도 이용은 거부할 수 있습니다.

## 유형별 근거와 판단 경계

**위치:** GPS 거리 계산 자체는 기기 안에서 수행합니다. 현재 위치를 지도 중심으로 사용하면 정밀 또는 근사 위치가 지도 범위 요청에 반영됩니다(`shelter_map.dart`, `meeting_point_screen.dart`). IP 기반 네트워크 지역 처리도 포함해 근사 위치는 GPS 권한만으로 전체 선택사항이라고 표시하지 않습니다. 임의 선택 지도/가족 장소를 실제 현재 위치라고 단정하지 않습니다. ‘위치로 지역 제안’은 별도 선택 Android Geocoder 기능입니다.

**식별/진단/상호작용:** Cloudflare 정책의 End Users/Network Data에는 IP·라우팅·시스템 구성·요청량/오류율 등 네트워크 동작 자료가 포함됩니다. OpenStreetMap 공식 정책은 IP·기기/OS·접속 시각/요청 경로와 기술 운영·보안·개선 처리를 안내합니다. 카카오 SDK 인증 헤더에는 기기 모델·OS·언어·패키지·서명 정보가 실제 구성됩니다. 이 접속·기술 요청 정보를 Google 유형의 기기/기타ID, 진단, 앱 상호작용으로 분류한 것은 구현과 공개 정책을 대조한 판단입니다. 이것이 모든 SDK의 상세 서버 로그 스키마를 제공받았다는 뜻은 아닙니다. 광고 ID·IMEI·전체 설치 앱 수집을 구현하거나 확인했다는 의미도 아닙니다.

**공유와 보관:** 카카오/OSM 네트워크 서비스, 제공자의 자체 보안·기술 처리까지 다루므로 ‘모두 개발자 지시만 따르는 처리자’ 또는 ‘사용자 행동 예외’로 일괄 면제하지 않고 공유를 표시합니다. 제공자의 요청 기록이 전부 메모리에서 즉시 제거됨을 입증할 수 없어 일시 처리만이라고 표시하지 않습니다. 특정 로그 보관기간을 만들어 적거나 영구 보관이라고 단정하지 않습니다.

**애널리틱스 목적:** 운영자가 별도 행동 분석 SDK를 넣었다는 뜻이 아닙니다. 제공자가 처리하는 요청/오류·서비스 기술 진단과 개선 목적을 포함합니다. 공개 정책에도 이 차이를 설명합니다. 광고·판매 목적을 추정해서 추가하지 않습니다.

## 수집 대상으로 포함하지 않는 기기 자료

- 가족 계획·이전 연락처·메모·선택 사진 복사본·준비물·저장한 시설/도로 지도·조회 캐시는 앱 저장소에서 처리하며 운영자 서버로 업로드하지 않습니다. 전체 주소록/사진 보관함 접근이나 백그라운드 위치 추적이 없습니다.
- 가족 공유는 미리보기 후 사용자가 선택한 외부 앱으로 전달하는 기능입니다. Google의 사용자 시작 전송 예외를 적용하며 인앱 채팅·가족 추적·자동 문자 전송으로 신고하지 않습니다. 사진 저장/가족 계획과 온라인 지도 요청은 구분합니다.
- 지원 메일은 외부 이메일 앱에서 사용자가 작성·전송합니다. safeKor Android가 발신 이메일/본문을 서버로 업로드하는 기능이 아닙니다. 운영자가 받은 문의는 정책의 별도 수동 삭제 절차를 따릅니다.
- 훈련 알림은 로컬 알림입니다. 선택형 시스템 민방공 알림 접근은 지원 시스템 패키지/UID를 먼저 검사하고 본문은 기기 안에서 선별합니다. 원문을 저장하거나 업로드하지 않습니다. 접근 권한의 고지·동의와 기기별 수신 호환성은 데이터 보안 표와 별도로 점검합니다.
- Android 읽어주기는 네트워크 불필요 한국어 음성만 선택합니다. 마이크 녹음 없음.
- iPhone 웹 푸시의 endpoint/암호화 키/선택 지역·관리 해시·전달 기록은 Cloudflare D1에 보관하지만 현재 Android 네이티브는 이 웹 구독 코드를 실행하지 않습니다. 이를 Android 푸시 토큰 수집으로 신고하지 않습니다.

## HTTPS 및 배포본 확인

- 앱 직접 제어 API/온라인 타일/도로 다운로드 URL은 HTTPS. 개발 전용 localhost HTTP 허용을 운영 경로라고 취급하지 않습니다.
- `kakao_map_sdk1.3.1`이 포함하는 `com.kakao.maps.open:android:2.15.2` AAR의 인증 요청 클래스 `MapAuthHttpClient`는 `HttpsURLConnection`을 사용합니다. 정적 확인한 네이티브의 인증·기술 요청·폰트 서버 주소도 HTTPS입니다. Google Play 설치본의 인증200/지도 표시를 이전 단계에서 확인했습니다.
- release manifest targetSdk36이며 cleartext/network security 예외 설정이 없습니다. 네이티브 코드 전체에 대한 동적 트래픽 감사 완료를 주장하지 않습니다. TLS/샌드박스 제한을 해제하지 않았고, 사용자가 에뮬레이터 종료를 요청한 후 재실행하지 않았습니다.
- SDK 바이너리 SHA256와 확인 범위: `artifacts/play-data-safety-verification.json`. 키·사용자 위치·메일 내용·원시 세션 로그는 포함하지 않습니다.

## 공개 정책과 검증

`workers/shelters/public/privacy.html`에 Android 처리 유형·기술/보안/개선 목적·외부 기록 삭제 한계를 보완하고 같은 공개 `/privacy` 주소로 배포했습니다. 시행일11/1 유지, 수정일11/3. Workers55개 테스트·TypeScript·배포 dry-run 통과 및 공개 페이지200/새 내용 반영 확인. Flutter 앱 동작/번들 변경이 없어 Flutter 테스트와 AAB 재생성은 이번 단계에서 수행하지 않았습니다.

실제 정부 발송/실기기 종단 수신이나 법적 적합성 인증을 이 검토로 완료했다고 표현하지 않습니다. SDK·서버·사용 목적이 바뀌면 공개 정책과 Play 신고를 함께 갱신합니다.
