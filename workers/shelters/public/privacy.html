회원가입 없이 사용하는 비상 대비 앱입니다.

가족 계획·저장한 대피소·개인 사진은 기기에 보관합니다. 온라인 시설 조회와 지도 사용 시에는 외부 서버가 요청 정보를 처리합니다. 로그인하지 않는다고 모든 정보가 기기에만 머무르는 것은 아닙니다.

1. 적용 범위와 운영자

이 방침은 safeKor가 운영하는 SAFE KOREA Android 앱과 iPhone PWA, 대피소 조회 API, 개인정보·문의 웹페이지에 적용됩니다. 앱은 상황별 행동요령·대피시설 조회·오프라인 준비와 선택형 알림 연결을 제공하는 민간 비상 대비 도구입니다.

운영 및 개인정보 문의: taetaeg@gmail.com. 이름·이메일·비밀번호로 가입하는 계정 기능은 없습니다.

2. 기기 안에서 처리하는 정보

  • 가족 대피 계획: 첫 번째·대체 만남 장소, 지도 핀, 약속·메모를 앱 저장공간에 보관합니다. 이전 버전에서 입력한 연락처 이름·전화번호가 남아 있을 수 있으나 현재 주소록을 읽거나 서버로 업로드하지 않습니다.
  • 저장한 대피소: 시설 정보, 주·대체 지정, 메모, 사용자가 선택해 복사한 출입구·시설 사진을 기기에 저장합니다. 사진 보관함 전체를 서버로 전송하지 않습니다.
  • PWA 저장: 가족 약속, 저장한 시설·주변 지도·사진·메모, 준비물과 마지막 조회 목록은 이 브라우저 저장공간에 보관합니다. 계정이나 운영자 사용자 DB에 업로드하지 않습니다. 저장 공간 부족·접근 차단 시 저장이 실패할 수 있고, 브라우저 사이트 데이터 삭제 시 사라집니다. 브라우저·운영체제의 보관 정책이 적용됩니다.
  • 준비물과 조회 자료: 준비물 체크와 마지막으로 조회한 시설 목록을 기기에 저장합니다. 운영자 서버에 가족·체크리스트 사용자 DB는 없습니다.
  • 현재 위치: 사용자가 GPS 버튼을 누르면 권한 확인 후 현재 위치를 한 번 요청해 거리 계산에 사용합니다. 앱은 백그라운드 위치 추적이나 위치 이동 이력을 저장하지 않습니다. 거리 계산은 기기에서 수행합니다. PWA에서도 버튼을 누를 때 브라우저 위치 서비스를 요청하며 좌표를 시설 API에 보내거나 영구 저장하지 않습니다. 위치 확인 과정에서 브라우저·운영체제의 위치 서비스 정책이 적용됩니다. 지도 표시·지역 제안을 함께 이용하면 아래 온라인 처리가 발생합니다.

3. 온라인 기능과 외부 처리

대피소 조회와 웹페이지

주변 지도 저장을 누르면 선택 시설 주변의 공개 지도 구역을 호스팅 서버에서 내려받습니다. 현재 GPS나 가족 약속은 그 요청에 넣지 않습니다.

지역별 시설 조회에는 선택한 시·군·구 코드가 전송됩니다. Cloudflare Workers는 API 호스팅·전송·캐시·네트워크 보안을 제공하며 접속 IP, 요청 주소·시각, 네트워크·기기 요청 정보를 처리할 수 있습니다. 시설 API는 GPS 좌표·가족 계획·사진·전화번호를 요청하거나 사용자 DB에 저장하지 않습니다. 원천 정부 사이트에는 지역 코드로 조회하며 사용자의 IP나 인증 헤더를 그대로 전달하지 않습니다. 직접 정부 조회를 사용하는 앱 빌드나 정부 원문 링크에서는 정부 사이트가 직접 접속 정보를 처리합니다.

지도·로드뷰·위치 기반 지역 제안

카카오 지도와 로드뷰를 열거나 이동·확대하면 지도 범위·좌표·접속 정보가 카카오 서비스에 전달됩니다. 현재 위치 또는 가족 만남 장소를 지도 중심에 표시하면 그 주변 범위도 지도 요청에 반영됩니다. 카카오 키가 없는 빌드는 OpenStreetMap 타일을 사용할 수 있으며, 요청 타일 범위·IP·앱/기기 요청 정보가 해당 서비스에 전달됩니다.

“현재 위치로 지역 제안”을 따로 선택하면 좌표를 Android의 주소 변환 서비스에 전달합니다. 실제 처리 제공자는 기기·운영체제 구성에 따라 다를 수 있습니다. 이 기능을 사용하지 않아도 지역을 직접 선택할 수 있습니다.

Android 앱 업데이트 확인(Shorebird)

Android 앱은 실행할 때 코드 업데이트 서비스 Shorebird(미국 Shorebird, Inc.)에 앱 식별자·앱 버전·적용된 업데이트 번호·플랫폼(Android)·CPU 종류를 보내 새 업데이트가 있는지 확인하고, 업데이트 적용과 실행 성공 여부를 보고합니다. 이 과정에서 접속 IP와 요청 시각이 처리될 수 있습니다. GPS 좌표·가족 계획·저장한 대피소·사진·연락처는 보내지 않습니다. 업데이트 확인에 실패해도 설치된 앱과 오프라인 기능은 그대로 사용할 수 있습니다. 세부 처리와 보관은 Shorebird 정책을 따릅니다.

Android 온라인 처리 항목과 목적

온라인 지도·시설 조회·연결 확인 시 처리되는 정보에는 대략적인 위치(허용한 위치의 정밀도, 지도 범위 또는 네트워크의 IP 기반 지역), 현재 위치를 중심으로 지도를 요청할 때의 정확한 위치, 요청한 지도·시설 구역과 접속 시각 같은 앱 상호작용, 기기 모델·OS·SDK 버전과 네트워크 상태에 관한 기술 진단 정보, 접속 IP 등 기기·접속 식별 정보가 포함됩니다. 카카오 지도 SDK의 인증 요청에는 앱 패키지·서명 정보와 기기 모델·OS·언어·SDK 버전이 사용됩니다. 광고 ID·주소록을 별도로 수집하는 광고 SDK를 추가하지 않았습니다.

이 정보는 지도·시설 조회와 네트워크 연결 제공, API 이용 인증·부정 사용 차단·보안, 제공자의 서비스 운영·오류 진단·성능 개선에 사용됩니다. 별도의 광고나 운영자 행동 분석 SDK는 없습니다. 제3자 제공자의 네트워크·기술 처리까지 수집·공유가 없다고 안내하지 않습니다. GPS 권한을 거부해도 네트워크 연결 확인 등에 따른 IP·기술 요청 정보 처리는 발생할 수 있습니다. 정확한 현재 위치의 지도 이용은 선택할 수 있습니다.

제공자의 접속·보안 기록을 모두 메모리에서 즉시 삭제한다고 보장하지 않으며 보관기간은 각 제공자의 정책에 따릅니다. 기기 안의 자료와 운영자가 받은 문의는 아래 방법으로 삭제할 수 있습니다. 운영자가 기기 안의 자료를 원격 삭제하거나 모든 외부 제공자의 네트워크 기록을 직접 조회·삭제할 수 있는 기능은 없습니다. Google Play 데이터 보안 표시의 삭제 여부는 이 외부 처리 범위까지 고려합니다.

사용자가 선택하는 공유·외부 링크

가족 공유는 내용을 미리 확인한 뒤 사용자가 선택한 외부 앱에 전달합니다. 경보가 울렸다는 이유로 문자를 자동 발송하지 않습니다. 선택한 앱의 전송·보관에는 해당 서비스 방침이 적용됩니다. 지도·라디오·공식 출처 링크도 외부 서비스로 이동합니다.

알림·음성

Android 훈련 알림은 사용자가 요청한 기기 내 테스트에 사용합니다. iPhone 선택형 웹 알림은 아래 설명처럼 동의 후 구독 주소·암호화 키·선택 지역과 전달 확인 기록을 서버에 보관합니다. Android 행동요령 읽기는 설치된 한국어 음성 중 네트워크 불필요 음성을 선택하며, 없으면 사용할 수 없음을 안내합니다. 마이크로 음성을 녹음하지 않습니다.

앱에 광고·행동 분석 SDK나 운영자 광고 프로파일링 기능을 넣지 않았습니다. 외부 제공자가 처리하는 정보의 세부 범위와 보관은 각 제공자 정책 및 실제 서비스 조건이 적용됩니다.

4. 문의 이메일

사용자가 문의를 보내면 회신을 위해 발신 이메일, 표시 이름, 문의 내용 및 자발적으로 첨부한 자료를 처리합니다. 이메일은 Gmail을 통해 처리됩니다. 문의 해결과 후속 대응을 위해 종료 후 최대 90일 보관한 뒤 삭제하는 것을 운영 기준으로 합니다. 법령상 보관 의무나 분쟁 보존 필요가 있으면 필요한 범위에서 별도로 보관하고 사유를 안내합니다.

주민등록번호, 비밀번호, 상세한 가족 개인정보, 민감한 사진이나 현재의 정확한 위치를 보내지 마세요. 화면 캡처에는 개인 내용을 가려 주세요. 이 이메일은 긴급 구조 접수 창구가 아닙니다.

5. 보관과 삭제

  • 기기 내 계획·메모·사진 복사본·체크리스트는 사용자가 삭제하거나 앱 데이터 삭제/앱 제거 시까지 보관합니다. 앱 안의 삭제·저장 해제 기능 또는 Android 설정의 앱 저장공간 삭제를 사용할 수 있습니다. PWA는 브라우저의 이 사이트 데이터 삭제로 전체 저장 내용을 지울 수 있습니다.
  • 전체 앱 데이터 삭제는 이전 버전 연락처와 캐시도 삭제합니다. 사진 보관함 원본과 외부 앱으로 이미 보낸 메시지는 해당 앱에서 별도로 삭제해야 합니다.
  • 서버의 지역별 시설 캐시는 공개 시설 자료이며 사용자별 기록이 아닙니다. 15분 후 재조회하고, 실패 시 24시간 미만의 이전 자료만 제공하도록 구성되어 있습니다.
  • 광고·분석 목적의 사용자 활동 기록과 Workers observability는 사용하지 않습니다. 선택형 웹 알림의 전달·표시·열기 확인 기록은 아래 설명에 따라 보관합니다. 이것이 Cloudflare·지도 제공자의 네트워크·보안 로그까지 전혀 없다는 뜻은 아닙니다. 외부 사업자의 보관·삭제는 해당 정책과 서비스 조건에 따릅니다.

선택 기능: Android 시스템 민방공 알림 연결

기본값은 꺼짐입니다. ‘휴대전화 경보 연결’에서 권한 범위에 동의한 뒤 Android의 알림 접근 설정에서 사용자가 직접 허용합니다. 이 권한 자체는 다른 앱 알림에도 접근할 수 있습니다. safeKor는 알림 내용에 접근하기 전에 발신 패키지·시스템 앱 여부·UID를 확인하고, 지원된 Google/AOSP 시스템 재난문자의 명확한 민방공 발령만 기기 안에서 선별합니다. 다른 앱의 알림 본문은 읽지 않으며, 재난문자 원문도 저장하거나 외부에 전송하지 않습니다.

연결을 위해 경보 종류, 시스템 알림 시각, 출처 패키지, 중복 방지 해시만 앱 전용 저장소에 보관합니다. 대기 경보는 2분 후 다음 확인 때 제거하고 마지막 중복 방지 해시·사용 설정은 연결을 끌 때 제거합니다. 제조사별 호환성·운영체제의 알림 내용 제한에 따라 연결되지 않을 수 있습니다. 앱 사용 중에는 행동 안내를 열고, 백그라운드에서는 별도 안내 알림을 누르는 방식입니다. 원래 시스템 재난문자의 소리나 표시는 바꾸지 않습니다.

앱의 연결 끄기와 Android 알림 접근 권한 철회는 별개입니다. 완전히 철회하려면 기기 설정에서 safeKor의 알림 접근 권한을 해제하세요. iPhone PWA에는 이 기능이 없습니다.

선택 기능: iPhone 웹 알림

홈 화면에 추가한 웹 앱에서 지역을 선택하고 동의한 뒤 알림 연결을 누를 때만 등록합니다. 알림 주소(endpoint), 기기 측 암호화 공개 키와 인증 비밀값, 선택 지역, 등록·만료 시각, 관리용 임의 토큰의 해시를 Cloudflare D1에 보관합니다. 푸시 구독 정보는 해당 기기의 알림 전달에만 사용하며 GPS·가족 계획·연락처를 포함하지 않습니다. 등록 관리용 토큰은 기기 브라우저에도 저장합니다.

암호화한 알림은 Apple Push Notification service로 전송합니다. Apple 서버 접수, 서비스워커의 알림 표시 확인, 알림 열기를 각각 구분하기 위해 임의 전달 식별자와 확인 시각을 기록합니다. Apple 서버 접수만으로 사용자가 수신·열람했다고 판단하지 않습니다. 테스트는 사용자가 요청한 기기에만 실제 경보가 아님을 표시해 보냅니다.

구독은 알림 연결 유지 및 전달을 위해 보관하며, 사용자의 해제 또는 Apple 구독 만료 응답을 확인하면 삭제합니다. 앱의 ‘알림 끄기 · 서버 등록 삭제’로 해제할 수 있고, 만료 또는 Apple의 구독 만료 응답을 확인하면 제거합니다. 전달 기록은 유효시간 종료 후 최대 24시간을 기준으로 다음 정리 작업에서 삭제합니다. 시스템 알림 권한 철회와 서버 등록 삭제는 별개이므로 서버 삭제 확인까지 앱에서 처리해 주세요. 접속 정보는 Cloudflare·Apple의 인프라에서 처리될 수 있습니다. Apple 개인정보처리방침도 확인할 수 있습니다.

정부 공개 API는 서버에서 조회합니다. 알림 권한 허용을 모든 정부 경보의 즉시 전달 보장으로 안내하지 않습니다.

6. 권한·선택권·보호 조치

위치와 알림 권한은 Android 설정에서 철회할 수 있습니다. PWA의 위치 권한은 브라우저·사이트 설정에서 철회할 수 있습니다. 위치를 거부해도 오프라인 행동요령과 수동 지역 선택을 사용할 수 있습니다. 앱은 전체 주소록·백그라운드 위치·마이크 권한을 요구하지 않습니다.

앱 저장정보는 앱 전용 저장공간을 사용하고 Android 자동 백업을 끕니다. 앱 자체의 별도 데이터베이스 암호화를 구현했다고 주장하지 않습니다. API·지도 타일·공식 원문 링크에는 HTTPS를 사용합니다. 기기 잠금과 운영체제 업데이트를 유지해 주세요.

운영자가 보유한 문의 정보의 열람·정정·삭제·처리정지를 요청하려면 아래 이메일로 연락해 주세요. 요청 확인에 필요한 최소한의 정보만 요청하며, 기기 안에만 있는 자료를 운영자가 원격으로 열람하거나 삭제할 수는 없습니다.
