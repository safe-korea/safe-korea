가족 계획·저장한 대피소·개인 사진은 기기에 보관합니다. 온라인 시설 조회와 지도 사용 시에는 외부 서버가 요청 정보를 처리합니다. 로그인하지 않는다고 모든 정보가 기기에만 머무르는 것은 아닙니다.

1. 적용 범위와 운영자

이 방침은 safeKor가 운영하는 SAFE KOREA Android 앱, 대피소 조회 API, 개인정보·문의 웹페이지에 적용됩니다. 앱은 비공식 비상 대비 도구이며 실제 정부 경보를 자동 수신하거나 구조를 요청하는 서비스가 아닙니다.

2. 기기 안에서 처리하는 정보

  • 가족 대피 계획: 첫 번째·대체 만남 장소, 지도 핀, 약속·메모를 앱 저장공간에 보관합니다. 이전 버전에서 입력한 연락처 이름·전화번호가 남아 있을 수 있으나 현재 주소록을 읽거나 서버로 업로드하지 않습니다.
  • 저장한 대피소: 시설 정보, 주·대체 지정, 메모, 사용자가 선택해 복사한 출입구·시설 사진을 기기에 저장합니다. 사진 보관함 전체를 서버로 전송하지 않습니다.
  • 준비물과 조회 자료: 준비물 체크와 마지막으로 조회한 시설 목록을 기기에 저장합니다. 운영자 서버에 가족·체크리스트 사용자 DB는 없습니다.
  • 현재 위치: 사용자가 GPS 버튼을 누르면 권한 확인 후 현재 위치를 한 번 요청해 거리 계산에 사용합니다. 앱은 백그라운드 위치 추적이나 위치 이동 이력을 저장하지 않습니다. 거리 계산은 기기에서 수행합니다. PWA에서도 버튼을 누를 때 브라우저 위치 서비스를 요청하며 좌표를 시설 API에 보내거나 영구 저장하지 않습니다. 위치 확인 과정에서 브라우저·운영체제의 위치 서비스 정책이 적용됩니다. 지도 표시·지역 제안을 함께 이용하면 아래 온라인 처리가 발생합니다.

3. 온라인 기능과 외부 처리

대피소 조회와 웹페이지

지역별 시설 조회에는 선택한 시·군·구 코드가 전송됩니다. Cloudflare Workers는 API 호스팅·전송·캐시·네트워크 보안을 제공하며 접속 IP, 요청 주소·시각, 네트워크·기기 요청 정보를 처리할 수 있습니다. 시설 API는 GPS 좌표·가족 계획·사진·전화번호를 요청하거나 사용자 DB에 저장하지 않습니다. 원천 정부 사이트에는 지역 코드로 조회하며 사용자의 IP나 인증 헤더를 그대로 전달하지 않습니다. 직접 정부 조회를 사용하는 앱 빌드나 정부 원문 링크에서는 정부 사이트가 직접 접속 정보를 처리합니다.

지도·로드뷰·위치 기반 지역 제안

카카오 지도와 로드뷰를 열거나 이동·확대하면 지도 범위·좌표·접속 정보가 카카오 서비스에 전달됩니다. 현재 위치 또는 가족 만남 장소를 지도 중심에 표시하면 그 주변 범위도 지도 요청에 반영됩니다. 카카오 키가 없는 빌드는 OpenStreetMap 타일을 사용할 수 있으며, 요청 타일 범위·IP·앱/기기 요청 정보가 해당 서비스에 전달됩니다.

“현재 위치로 지역 제안”을 따로 선택하면 좌표를 Android의 주소 변환 서비스에 전달합니다. 실제 처리 제공자는 기기·운영체제 구성에 따라 다를 수 있습니다. 이 기능을 사용하지 않아도 지역을 직접 선택할 수 있습니다.

사용자가 선택하는 공유·외부 링크

가족 공유는 내용을 미리 확인한 뒤 사용자가 선택한 외부 앱에 전달합니다. 경보가 울렸다는 이유로 문자를 자동 발송하지 않습니다. 선택한 앱의 전송·보관에는 해당 서비스 방침이 적용됩니다. 지도·라디오·공식 출처 링크도 외부 서비스로 이동합니다.

알림·음성

알림은 사용자가 요청한 기기 내 훈련 테스트에 사용합니다. 원격 푸시 토큰을 수집하지 않습니다. Android 행동요령 읽기는 설치된 한국어 음성 중 네트워크 불필요 음성을 선택하며, 없으면 사용할 수 없음을 안내합니다. 마이크로 음성을 녹음하지 않습니다.

앱에 광고·행동 분석 SDK나 운영자 광고 프로파일링 기능을 넣지 않았습니다. 외부 제공자가 처리하는 정보의 세부 범위와 보관은 각 제공자 정책 및 실제 서비스 조건이 적용됩니다.

사용자가 문의를 보내면 회신을 위해 발신 이메일, 표시 이름, 문의 내용 및 자발적으로 첨부한 자료를 처리합니다. 이메일은 Gmail을 통해 처리됩니다. 문의 해결과 후속 대응을 위해 종료 후 최대 90일 보관한 뒤 삭제하는 것을 운영 기준으로 합니다. 법령상 보관 의무나 분쟁 보존 필요가 있으면 필요한 범위에서 별도로 보관하고 사유를 안내합니다.

주민등록번호, 비밀번호, 상세한 가족 개인정보, 민감한 사진이나 현재의 정확한 위치를 보내지 마세요. 화면 캡처에는 개인 내용을 가려 주세요. 이 이메일은 긴급 구조 접수 창구가 아닙니다.

5. 보관과 삭제

  • 기기 내 계획·메모·사진 복사본·체크리스트는 사용자가 삭제하거나 앱 데이터 삭제/앱 제거 시까지 보관합니다. 앱 안의 삭제·저장 해제 기능 또는 Android 설정의 앱 저장공간 삭제를 사용할 수 있습니다.
  • 전체 앱 데이터 삭제는 이전 버전 연락처와 캐시도 삭제합니다. 사진 보관함 원본과 외부 앱으로 이미 보낸 메시지는 해당 앱에서 별도로 삭제해야 합니다.
  • 서버의 지역별 시설 캐시는 공개 시설 자료이며 사용자별 기록이 아닙니다. 15분 후 재조회하고, 실패 시 24시간 미만의 이전 자료만 제공하도록 구성되어 있습니다.
  • 운영자 코드의 사용자 활동 로그와 Workers observability는 꺼져 있습니다. 이것이 Cloudflare·지도 제공자의 네트워크·보안 로그까지 전혀 없다는 뜻은 아닙니다. 외부 사업자의 보관·삭제는 해당 정책과 서비스 조건에 따릅니다.

6. 권한·선택권·보호 조치

위치와 알림 권한은 Android 설정에서 철회할 수 있습니다. PWA의 위치 권한은 브라우저·사이트 설정에서 철회할 수 있습니다. 위치를 거부해도 오프라인 행동요령과 수동 지역 선택을 사용할 수 있습니다. 앱은 전체 주소록·백그라운드 위치·마이크 권한을 요구하지 않습니다.

앱 저장정보는 앱 전용 저장공간을 사용하고 Android 자동 백업을 끕니다. 앱 자체의 별도 데이터베이스 암호화를 구현했다고 주장하지 않습니다. API·지도 타일·공식 원문 링크에는 HTTPS를 사용합니다. 기기 잠금과 운영체제 업데이트를 유지해 주세요.

운영자가 보유한 문의 정보의 열람·정정·삭제·처리정지를 요청하려면 아래 이메일로 연락해 주세요. 요청 확인에 필요한 최소한의 정보만 요청하며, 기기 안에만 있는 자료를 운영자가 원격으로 열람하거나 삭제할 수는 없습니다.
