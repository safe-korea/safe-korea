이메일 앱 열기

이메일 앱이 없으면 주소를 복사해 사용하세요. 보내기 버튼을 누르기 전까지 자동 전송되지 않습니다. 긴급 구조 접수 창구는 아닙니다.

앱 문제를 알려주실 때

  • 기기 모델, 운영체제 버전, 앱 버전 또는 PWA 브라우저 종류을 적어 주세요.
  • 어느 화면에서 어떤 동작을 했는지 알려 주세요.
  • 스크린샷은 선택 사항입니다. 이름·가족 약속·전화번호·정확한 위치 등 개인정보를 가린 뒤 첨부해 주세요.

비밀번호·인증키·주민등록번호를 요청하지 않습니다. 문의 메일을 보내면 발신 주소와 문의 내용이 답변을 위해 처리됩니다. 문의 종료 후 최대 90일 보관을 운영 기준으로 하며 자세한 내용은 개인정보처리방침에 안내합니다.

기기에 저장한 정보를 삭제하려면

가족 계획 삭제, 대피소 저장 해제, 사진·메모 수정, 준비물 체크 해제를 이용하세요. 모든 정보와 이전 연락처를 지우려면 Android 설정 → 앱 → SAFE KOREA → 저장공간 → 데이터 삭제를 이용하거나 앱을 제거하세요. PWA의 전체 기록은 브라우저 설정에서 이 사이트 데이터를 삭제하면 지워집니다. 사진 보관함 원본과 이미 공유한 메시지는 해당 앱에서 따로 삭제해야 합니다.

경보·지도·인터넷 안내

  • 실제 정부 경보를 자동 수신하지 않습니다. 훈련 화면과 테스트 알림은 실제 경보가 아닙니다.
  • GPS를 거부해도 지역 직접 선택과 행동요령을 사용할 수 있습니다.
  • 새 시설 조회·온라인 지도·로드뷰·온라인 라디오는 인터넷 연결이 필요합니다. 동봉 행동요령과 미리 저장한 대피소·주변 지도·가족 계획·준비물은 앱과 PWA에서 오프라인으로 확인할 수 있습니다. PWA 앱 파일은 사전 저장해야 하며 브라우저가 저장 공간을 정리하면 다시 저장해야 합니다.
  • 대피소 등재·거리 정보는 현재 개방이나 이동 경로의 안전을 보장하지 않습니다. 재난문자·정부 방송·현장 지시를 우선하세요.

iPhone 웹 알림 등록 삭제

설치한 앱의 나의 준비 → 알림 설정 → 알림 끄기 · 서버 등록 삭제를 누르세요. 인터넷 연결이 있어야 서버 삭제를 확인할 수 있습니다. 기기 설정의 알림 권한 철회만으로 서버 등록이 즉시 삭제되지는 않습니다. 브라우저 데이터 삭제 전에 알림 설정에서 서버 등록을 먼저 삭제해 주세요. 관리 토큰을 잃으면 기기에서 구독을 해제할 수 있지만 서버 삭제를 확인하기 어려울 수 있습니다. Apple의 구독 만료 응답을 확인하면 해당 등록도 정리됩니다.
