# SAFE KOREA MVP

대한민국 시민을 위한 한국어 오프라인 비상 대비 Flutter MVP입니다. **비공식 프로토타입이며 실제 정부 경보를 수신하지 않습니다.** 모의 화면에는 항상 `훈련 / 테스트`가 표시됩니다.

**출시 방향: Android는 Google Play 네이티브 앱, iPhone은 PWA.** iOS App Store 출시는 진행하지 않으며 기존 iOS 코드는 보존합니다. PWA는 설치 온보딩·오프라인 행동요령 미리보기를 구현했으며 웹 지도·GPS·가족 저장은 아직 미구현입니다. [출시 점검](RELEASE_CHECKLIST.md) · [PWA 전환 계획](PWA_PLAN.md).

## Cloudflare Workers 데이터 서버

지역별 시설 조회·캐시 API와 Android/PWA 연결을 구현했습니다. **2026-11-01 API 공개 배포 완료:** https://safe-korea-shelter-api.trovapp.workers.dev . PWA 사이트 호스팅은 아직 미배포입니다. PWA는 API 주소를 설정하면 지역별 목록과 외부 카카오 지도 연결을 사용할 수 있습니다. `--dart-define-from-file=config/api.production.json`으로 공개 API를 연결합니다. 설정 없는 기본 PWA 빌드는 정부 사이트 링크를 제공합니다. 로그인·개인 DB·실제 경보 서버는 추가하지 않았습니다. [실행 및 배포 전 확인](workers/shelters/README.md) · [서버 구성](SERVER_PLAN.md).

## 앱 구성

네이티브 앱은 네트워크 단절 또는 데이터 서버 연결 확인 실패 시 홈에 **오프라인 기능 모아보기**를 표시합니다. 다른 화면은 닫지 않고 상단 바로가기를 제공합니다. 홈 하단에서 수동 접근도 가능합니다. PWA는 저장된 행동요령만 우선 표시합니다. 상태 변화·복귀 시 기존 서버 `/health`를 확인하며 요청 IP가 처리될 수 있습니다. Wi-Fi 연결 유지 중 외부 회선 단절은 즉시 감지가 보장되지 않습니다.

홈은 **지금 할 행동 → 저장한 대피소·가족 만남 장소·준비물**을 우선합니다. 홈 행동 안내는 받은 경보 종류를 직접 고른 후 실내·실외·이동 중 안내를 보여줍니다. [핵심 동선 QA 결과](FOCUS_UX_QA.md).

하단 메뉴로 **홈 · 대피소 · 행동강령 · 나의 준비**를 이동합니다. 가족 계획은 저장된 내용을 먼저 읽고 필요할 때 수정합니다. 훈련에는 선택형 연습 체크가 있습니다. 준비물 체크와 가족 계획은 기기에만 저장됩니다.

완료 범위와 남은 검증은 [MVP_CHECKLIST.md](MVP_CHECKLIST.md), 카카오 지도 키 연결은 [KAKAO_SETUP.md](KAKAO_SETUP.md)를 참고하세요. 키를 나중에 넣어도 되며 현재 앱의 기본 기능과 지도는 키 없이 실행됩니다.

## 대피소 지도 사용법

1. **주변 대피시설**에서 시·도와 시·군·구를 선택합니다.
2. **선택 지역 대피소 불러오기**를 누르면 공식 국민안전24 지도에서 해당 지역의 민방위 대피소를 조회합니다. 현재 화면의 표시 범위와 조회 시각을 확인하세요.
3. **온라인 지도 열기**를 누르면 실제 시설 핀이 표시됩니다. 숫자는 가까운 시설의 묶음이며 누르면 확대됩니다. 충분히 확대해도 겹치는 시설은 선택 목록에서 고릅니다. 기본 지도에서는 묶음을 길게 눌러 바로 목록을 열 수도 있습니다. 숫자 위치는 실제 출입구가 아닙니다.
4. **현재 위치로 지역 찾기**를 펼쳐 별도 안내를 확인한 뒤 지역 제안을 요청할 수 있습니다. 기기의 주소 변환 서비스가 제공한 이름을 공식 지역 목록과 대조합니다. 시도만 확인되면 시군구는 비워 두며 직접 선택하기 전까지 조회할 수 없습니다. 경계·행정구역 명칭 변경·서비스 미지원 시 직접 선택하세요. **GPS 현재 위치 확인**을 허용하면 받은 지역 안에서 직선거리순으로 정렬합니다. GPS 위치에 따라 다른 지역을 자동 조회하지 않으므로 필요한 인접 지역은 직접 선택하세요.
5. 마지막으로 조회한 지역 한 곳의 목록은 기기에 저장되어 다음 실행부터 인터넷 없이도 검색할 수 있습니다. **대피소 저장**을 누른 개별 시설은 지역을 바꿔도 **저장한 대피소**에서 검색·열람·해제할 수 있습니다. **공식 자료 다시 확인**으로 저장한 시설의 현재 목록 정보를 조회할 수 있습니다. 변경된 이름·주소·좌표를 반영하되 처음 저장한 시각은 보존합니다. 조회에서 찾지 못하거나 일부 행이 누락되면 기존 정보와 미확인 표시를 유지하며 폐쇄로 단정하지 않습니다. 공식 조회 시각·기기 저장 시각·재확인 시각을 구분하며 자동 최신화되지 않습니다. 지도 배경은 온라인 전용입니다.
6. 기본 OSM 지도 배경이 실패하거나 15초 이상 응답이 없으면 **지도 다시 시도** 또는 **시설 목록 보기**를 이용하세요. 목록은 현재 조회/저장된 시설 데이터로 열리며 추가 네트워크 요청을 하지 않습니다. 카카오 SDK 인증·초기 준비 오류 시 기본 지도로 전환합니다. 카카오 인증·배경·핀·확대는 시뮬레이터에서 검증했으며 실제 기기의 통신 단절·복구 검증은 남아 있습니다.
7. 조회 후에는 지역 입력이 접힙니다. **지역 변경**을 눌러 다른 지역을 조회하세요. UI 설계와 접근성 검토는 [DESIGN.md](DESIGN.md)에 기록합니다.

추가 지역 검증에서 부산 중구는 전체/지도 51건 일치를 확인했고, 제주시는 전체 812건과 지도 479건이 달랐습니다. 이런 지역은 앱이 교체를 거부하고 오류 안내 옆의 정부 공식 검색으로 연결합니다. 모든 지역의 자료 완전성을 검증한 것은 아닙니다.

처음 설치할 때 동봉 시설은 0건입니다. 전국 전체 시설을 미리 수집하거나 자동 최신화하지 않습니다. 조회 실패 시 기존 자료를 유지하며 잘못된 좌표·중복은 제외 수를 표시합니다. 공식 지도 응답에 시설별 갱신일이 없어 `제공되지 않음`으로 표시합니다. 조회 시각을 시설 갱신일로 대신하지 않습니다.

공식 사이트의 내부 조회 경로를 사용하는 MVP이며, 공개 API로서의 버전·가용성·운영 이용 조건은 보장되지 않습니다. 사이트 변경/장애 시에는 **정부 공식 시설 검색 열기**를 이용하세요. 상세한 관측 근거는 DATA_SOURCES.md에 기록했습니다.

GPS는 앱에서 저장하지 않습니다. **거리 계산**은 기기 안에서 처리합니다. **위치로 조회 지역 제안받기**는 별도 안내 후 사용자가 누를 때만 좌표를 Apple/Google 등 기기 주소 변환 서비스에 전달할 수 있습니다. 이 서비스는 [geocoding 공식 패키지](https://pub.dev/packages/geocoding)의 OS 기능을 사용하며 앱 자체 서버·유료 API 키는 추가하지 않습니다. 2분 이상 오래되거나 오차가 1km를 넘는 위치로는 지역 변환을 요청하지 않습니다. 시설 조회 시 지역 코드와 접속 IP가 설정된 Workers 또는 직접 정부 사이트에 전달됩니다. Workers는 원천 조회에 지역 코드만 사용하고 사용자 IP를 원천에 전달하지 않습니다. 온라인 지도는 별도 선택 시 조회하며, 지도 제공자에 IP와 조회 범위가 전달됩니다. 지도는 오프라인 기능에 포함되지 않습니다. OSM 저작자 표시·앱 User-Agent·기본 타일 캐시를 사용하며 대량 다운로드는 하지 않습니다.

가족 계획은 암호화되지 않은 기기 내부 SQLite에 저장합니다. Android 앱 백업은 비활성화했고 iOS Documents는 저장 전 백업 대상에서 제외합니다. 자동 연락, 가족 위치 추적, 로그인, 개발자 분석 도구, 개인 정보 저장 서버, Firebase는 없습니다. 공용 시설 조회용 Workers는 별도로 운영하며 네트워크 제공자는 요청 정보를 처리합니다. 기기 분실·고장에 대비해 종이 연락카드도 보관하세요.

## 구조

- `lib/screens`: 홈, 훈련, 행동강령, 시설/지도, 가족 계획
- `lib/models`: 공식 시설 자료 검증 및 거리 계산

## 테스트 알림

홈 하단 **테스트 알림 설정 → 지금 테스트 알림 보내기**에서 기기 알림 권한을 요청합니다. 앱 시작 시에는 권한을 요청하거나 알림을 보내지 않습니다. 소리와 Android 진동은 기본 꺼짐이며 직접 켤 수 있습니다. iPhone 진동은 OS 설정을 따릅니다. 알림 제목·본문은 훈련임을 표시하며 누르면 훈련 화면을 엽니다. 앱 종료 후 알림을 눌러 실행하는 경로도 연결했습니다. 테스트 알림 지우기는 이 앱의 테스트 알림 1개만 지웁니다.

[flutter_local_notifications](https://pub.dev/packages/flutter_local_notifications) 22.3.3 사용. Android 채널은 소리/진동 조합별로 분리합니다. 사용자가 OS에서 바꾼 채널 설정, 무음/집중 모드, 알림 차단은 우회하지 않습니다. 예약·원격 푸시·실제 정부 경보 자동 수신 기능은 없습니다. 네트워크 없이 동작하는 수동 테스트입니다. 실제 기기의 소리·진동, 알림 센터 탭 및 종료 상태 실행은 추가 수동 검증이 필요합니다.

경보 훈련 진입 화면은 **먼저 대피 → 준비된 배낭 → 대피 후 정부 안내** 순서입니다. 빨간 경보 영역에 대피시설 버튼을 크게 보여주며 손 닿는 물품만 챙기고 없으면 바로 대피하도록 안내하며, 행동요령은 펼쳐서 봅니다. 테스트 알림을 눌러도 같은 화면으로 연결됩니다. 실제 정부 경보 수신 상태는 변하지 않았습니다.

공습 훈련의 빨간 영역에는 **지금 즉시 대피하세요 / 물품을 찾느라 지체하지 마세요**를 우선 표시하고, **주변 대피소 보기**를 실내·실외 선택보다 앞에 배치합니다. 수동 상황별 행동요령도 공습을 선택하면 같은 우선순위를 사용합니다. 화학·핵 등 다른 상황의 예외 안내는 유지합니다.

**훈련 시작 후 경과 / 대피 여유시간 아님** 타이머는 훈련 화면을 연 때부터 계산합니다. 지도를 열거나 앱이 백그라운드에 있는 동안에도 같은 세션의 경과 시간을 반영합니다. 훈련 화면을 닫고 다시 열거나 앱 프로세스가 종료되면 새로 시작하며 기록은 저장하지 않습니다. 공격 도달 시각·남은 안전 시간·대피 제한시간을 의미하지 않습니다. 수동 행동요령에는 수신한 경보가 없으므로 경보 수신 타이머를 표시하지 않습니다.

### 사이렌 테스트와 화면 구성

홈 → 테스트 알림 설정 → **사이렌 켜기** → **지금 테스트 알림 보내기**. 기본 알림음 대신 앱에 동봉한 8초 상승·하강 사이렌 예시을 요청합니다. Android raw 리소스와 iOS 앱 번들에 같은 PCM WAV를 포함하며 외부 다운로드는 없습니다. Android의 기존 기본음 채널과 새 사이렌 채널은 분리했습니다. 무음/집중 모드와 사용자가 변경한 OS 채널 설정은 그대로 적용됩니다. 켜기 스위치 자체나 훈련 화면 진입만으로 소리를 재생하지 않습니다.

음원은 scripts/generate_drill_siren.py로 직접 합성한 앱 훈련용이며 공식 정부 사이렌 녹음이 아닙니다. 자동 검증에서는 소리 설정·번들 포함·음원 길이/클리핑만 확인했고 실제 기기 청취는 미검증입니다.

홈, 행동강령, 나의 준비, 대피소 검색 도입부, 가족 계획, 알림 설정에도 공통 제목·아이콘·카드 디자인을 적용했습니다. 지도 데이터 및 지도 제공자 자체는 변경하지 않았습니다.

## 가족 만남 장소

홈 또는 나의 준비 → **가족 만남 장소**에서 첫 번째 장소, 대체 장소, 가족 약속을 저장합니다. 연락처 입력은 제거했으며 기존 연락처 값은 수정/삭제하지 않습니다. ‘저장된 계획 삭제’는 장소 이름·좌표·약속만 지웁니다.

**첫 번째 장소 지도에서 지정 / 대체 장소 지도에서 지정** → 지도를 확대하고 원하는 지점을 누르거나 ‘지도 중앙에 핀 놓기’ → **이 위치 선택** → 가족 화면에서 **기기에 저장**. 선택 뒤 가족 화면을 저장하기 전에는 임시 변경입니다. 뒤로 가면 미저장 확인이 뜹니다. 장소 이름은 직접 입력하며 주소 검색·자동 좌표 변환은 수행하지 않습니다.

저장된 각 장소는 **지도 보기**로 핀을 다시 확인할 수 있습니다. 카카오 키가 설정된 앱에서는 카카오 온라인 지도를 사용하며 키 없는 개발 환경은 기본 OSM 지도입니다. 열 때 지도 제공자에게 IP와 조회 범위가 전달됩니다. 앱 서버에는 이름/좌표를 보내지 않고 GPS도 자동 요청하지 않습니다. 지도 배경 실패 시 재시도하거나 이름만 저장할 수 있습니다. 이름·좌표는 오프라인 열람 가능하며 가족에게 자동 공유되지 않습니다. 가족 만남 장소는 공식 대피시설 또는 안전한 경로를 의미하지 않습니다.

### 가족에게 미리 공유

장소를 저장한 뒤 **가족에게 공유 → 내용 확인 → 카카오톡 등으로 공유**에서 휴대폰 공유 창을 엽니다. 카카오톡이 설치되어 공유를 지원하면 해당 앱과 받을 상대를 직접 선택하세요. 메시지 공유 자체는 별도 카카오톡 SDK/API 키나 앱 서버 없이 share_plus의 OS 공유 기능을 사용합니다. 카카오톡 미설치/호환 문제에는 **내용 복사**로 원하는 대화방에 붙여 넣을 수 있습니다.

첫 번째·대체 장소와 지정한 핀의 카카오 지도 링크가 포함됩니다. 가족 약속 메모는 기본 제외이며 선택하면 포함됩니다. 예전 연락처 정보는 공유하지 않습니다. 수정 중인 내용은 저장 후 공유해야 합니다. 외부 앱에 전달하는 내용 전체를 미리 보여 주며 자동 메시지 발송은 하지 않습니다. 공유 창 결과를 메시지 도착/안전 확인으로 해석하지 않습니다. 지도 링크 확인에는 인터넷이 필요하고 SAFE KOREA 설치는 필요하지 않습니다. 실제 카카오톡 수신/전송 검증은 남아 있습니다.

### 화면 가독성 개선 (2026-11-01)
홈의 반복 설명을 줄이고 가족 만남 장소 접근 순서를 높였습니다. 가족 계획의 좌표는 상세에서 확인하고, 공유 화면에서는 장소 요약을 먼저 봅니다. `전송 내용 전체 보기`에서 지도 URL을 포함한 메시지를 확인할 수 있습니다. 대피소 화면은 선택 지역 자료만 표시하며 상세 집계는 `자료 출처와 조회 시각`에 있습니다.

### 경보별 행동 안내와 신호 (2026-11-01)

### 행동 그림과 목록 정렬 (2026-11-01)
훈련과 상황별 행동 화면은 계단·건물·창문·방송 등의 픽토그램, 짧은 행동 제목, 설명 한 줄로 구성합니다. 긴 설명을 아이콘으로만 대체하지 않고 침수·화학·핵 등 행동이 달라지는 조건을 바로 표시합니다. 글씨 확대 시 줄 수를 제한하거나 말줄임표로 숨기지 않습니다.
대피소 목록에서는 시설명·주소·직선거리를 확인하고 **시설을 눌러 상세 정보와 저장 버튼**을 엽니다. 저장한 시설 목록과 지도 핀 상세에서도 기존 저장 기능을 이용할 수 있습니다.

내부 화면의 날짜·출처는 항목별로 나누고 큰 글씨에서는 위아래로 표시합니다. 저장한 시설의 날짜는 `조회·저장 정보`, 행동강령 출처는 `출처와 확인 날짜`에서 볼 수 있습니다. 가족 장소·공유는 구분 라벨과 장소명을 같은 시작선에 배치합니다. 홈 구성은 유지했습니다.

### 현재 위치 사용

대피소 화면 상단의 **GPS 현재 위치 확인**을 누르면 권한을 요청하고 한 번 위치를 가져옵니다. 조회한 지역의 시설을 직선거리순으로 정렬하며, **온라인 지도 열기**에서 마지막 확인 위치를 파란 표시로 보여줍니다. 확인 시각과 오차를 확인하세요. 실시간 추적/안전한 경로 안내는 아닙니다. **현재 위치 표시 지우기**로 위치를 제거할 수 있습니다. 지도 열기는 별도 동작이며, 현재 위치 주변의 지도 조회 범위가 지도 제공자에게 전달됩니다. 다른 지역 시설은 **지역 변경 → 현재 위치로 지역 찾기** 또는 직접 선택으로 조회하세요.

저장한 대피소는 시설명·주소·현장 확인 안내와 지도 버튼을 먼저 보여줍니다. 재조회/출처/저장 해제는 **조회·저장 정보**를 펼쳐 이용하세요. 행동강령의 각 문단은 짧은 소제목과 상황별 아이콘으로 구분합니다.

### 로그인 여부

현재 MVP는 로그인 없이 사용합니다. GPS는 별도의 OS 위치 권한으로 접근하며, 계정 인증이 위치 권한을 대신하지 않습니다. 가족 계획·저장 시설·준비물은 로컬에 보관하고 다른 휴대폰으로 자동 동기화하지 않습니다. 계정 기반 동기화·복구·가족 초대가 필요해질 때 선택형 계정을 별도 설계합니다. 핵심 대피 안내는 로그인이나 GPS 허용 없이도 접근할 수 있습니다.

실제 정부 경보 연계는 [상세 조사 결과](ALERT_INTEGRATION_REVIEW.md)를 참고하세요. 공식 문자 조회 API는 있으나, 자동 사이렌용 즉시 전달은 승인·지연·이용 조건 검증이 별도로 필요합니다.

### 내부 화면 재점검 (2026-11-01)
상세 내용을 펼쳐도 제목·본문·버튼의 정렬이 유지되도록 정리했습니다. 대피소 화면의 **저장한 대피소 · 오프라인 목록** 버튼으로 저장 시설을 바로 엽니다. 저장된 이름·주소는 인터넷 없이 확인할 수 있지만 지도와 최신 공식 자료 조회에는 인터넷이 필요합니다.

GPS 제안 지역 바로 조회와 시설별 출입구 사진·메모를 구현했습니다. 실기기 검증과 실제 정부 경보 연계 검토는 별도로 필요합니다. 필수 로그인은 추가하지 않습니다.

페르소나 QA: [QA_REPORT.md](QA_REPORT.md)의 최신 절에 상황별 7개 페르소나, MBTI 16유형 보조 시나리오, 테스트 연결과 미충족 요구를 기록했습니다. MBTI는 창작한 사용 습관 가설이며 앱의 안전 안내를 유형별로 바꾸지 않습니다. 페르소나 테스트 추가 후 Flutter 90건·Python 7건 및 정적 분석 통과.

MBTI 후속 QA: 유형별 독립 위젯 시나리오 16건을 실제 실행했고 모두 통과했습니다. 전체 Flutter 검사는 106건, Python 7건이며 format/analyze도 통과했습니다. 세부 실행 결과·테스트 격리 범위는 QA_REPORT.md의 마지막 절을 참고하세요.

UX/UI 시각 검토: 대피소 화면은 지도 열기를 주 동작으로 먼저 보여주고, 저장 목록이 비어 있으면 ‘대피소 찾아서 저장하기’로 이동할 수 있습니다. 입력창 테두리·알림 문구·지도 선택 버튼 간격도 보완했습니다. 실제 사용자 이해도 검증 계획과 화면별 판단은 QA_REPORT.md 마지막 절에 기록했습니다.

가족 계획 작성·수정 시 **기기에 저장** 버튼은 화면 하단에 표시됩니다. 준비물 체크 행과 상황 선택 체크 표시로 선택 상태를 구분합니다.


### 출입구 사진과 대피 지원 (2026-11-01)

1. **대피소 → 시설 저장 → 우선순위·사진·메모 추가**에서 주/대체 대피소를 각각 한 곳 지정합니다. 저장 목록에서는 지정한 시설이 먼저 나오며, 공습 훈련에서는 지정 시설 바로 가기가 표시됩니다. 지정은 개인 계획으로, 현재 개방이나 이동 안전을 뜻하지 않습니다.
2. **사진 보관함에서 선택**으로 시설별 최대 3장을 추가하고 **기기에 저장**합니다. 사진·출입구 메모는 개인 기록이며 공식 사진이 아닙니다. 현재 연결한 공식 시설 응답에는 사진 필드가 없으므로 정부 제공 사진을 자동 연결하지 않습니다.
3. 사진은 긴 변 1280px 이하 PNG로 재인코딩하여 EXIF/GPS 메타데이터를 제거하고 기존 내부 SQLite에 저장합니다(선택 파일 20MiB 이하, 변환 결과 장당 6MiB 이하). 원본/캐시 파일 경로에 의존하지 않아 앱 재실행·오프라인에서도 확대할 수 있습니다. 별도 업로드·클라우드 동기화는 없으며 저장 해제/앱 삭제 시 함께 삭제됩니다. 원본 사진은 보존합니다. Android 중단 선택은 기록 화면을 다시 열어 명시적으로 미리보기에 추가해야 하며 다른 시설에 자동 연결하지 않습니다.
4. **현재 위치로 지역 찾기 → 이 지역 대피소 바로 조회**로 확인한 시군구를 조회합니다. 지역 확인 전 자동 조회하지 않고, 불명확한 시군구는 직접 선택하게 합니다. GPS를 지역 선택과 거리 정렬에 재사용합니다.
5. 상황별 행동요령의 **행동요령 읽어주기**는 명시적으로 누를 때만 기기 한국어 음성을 사용합니다. 중지, 상황 변경, 페이지 이동, 백그라운드 진입 시 정지합니다. 한국어 음성이 없거나 실패하면 글 안내를 유지합니다. Android는 설치된 한국어와 네트워크 불필요 음성만 선택합니다. 실제 음성 재생/오프라인 지원은 기기·설치 음성에 따라 실기기 검증이 필요하며, 기존 동봉된 테스트 알림 음원과는 별도 기능입니다.
6. **가족 만남 장소 상단 말풍선(내 상태 공유)** 또는 **공습 훈련 → 대피 후 할 일·상태 공유**에서 직접 상태를 선택하고 보낼 내용을 확인합니다. GPS 자동 첨부/자동 문자/도착 감지는 없으며 공유 앱에서 받는 사람과 발송을 결정합니다. 훈련 경로에는 공유 본문에도 훈련 표시가 유지됩니다. 대피 후 안내는 기존 행정안전부 공습·경보해제 요약을 재구성했습니다.

구현 참고: [Flutter image_picker](https://pub.dev/packages/image_picker), [flutter_tts](https://pub.dev/packages/flutter_tts). iOS 사진 선택 권한 설명과 Android TTS 서비스 조회 선언을 추가했습니다. flutter_tts 4.2.5는 현재 iOS CocoaPods 호환 경로를 사용하며 Android KGP/향후 Flutter 호환 경고가 있어 SDK 업그레이드 전에 재검증해야 합니다. 현재 두 플랫폼 빌드는 성공했습니다.

최신 검증: 정적 분석 이슈 0, Flutter 120건·Python 7건 통과. 새 사진·공유 흐름은 iPhone 17 Pro 및 Android API 36 통합 테스트를 통과했습니다. 이전 절의 테스트 수는 해당 단계의 기록입니다.

시설 좌표와 IP가 카카오에 전달되지만 현재 GPS를 요청하거나 보내지 않습니다. 로드뷰 사진은 온라인 전용이며 출입구·개방 여부와 다를 수 있습니다. 기존 개인 사진은 삭제하지 않고 저장 목록의 **내 기록 · 선택** 아래에 보관합니다.

### 가족 지도 통일

로컬 카카오 키가 설정된 앱에서는 가족 만남 장소 선택·보기에도 카카오 지도를 사용하며 가족 공유 링크도 카카오 좌표 링크입니다. 기존 저장 좌표는 유지합니다. 지도 배경/로드뷰에는 인터넷이 필요하고, 저장된 주소·좌표·약속·사진·행동요령의 오프라인 보관과는 구분됩니다. 키 없는 개발 환경에는 기존 OSM 지도가 남아 있습니다. 오프라인 FM 라디오 수신은 구현되어 있지 않으며 기기 하드웨어와 SDK 이용 조건 확인이 필요합니다.

### 라디오 연결과 비상용품 준비

- **나의 준비 → 라디오 연결**, **공습 대피 후 할 일 → KBS 라디오 연결**에서 KBS 공식 콩 안내 사이트를 엽니다. 인터넷이 필요하며 앱 내 스트리밍·자동 재생·오프라인 FM 수신은 제공하지 않습니다. 사이트에서 이용/설치 안내를 확인합니다. 연결 앱을 열지 못하면 재시도하거나 공식 주소를 복사할 수 있습니다.
- `통신이 끊겼다면`에서 휴대용 라디오와 지원 기기 기본 FM 라디오 안내를 오프라인으로 볼 수 있습니다. 모든 휴대폰의 FM 지원을 가정하지 않습니다.
- **개발용 debug 앱의 나의 준비 → 비상용품 준비**에 물·간편식, 손전등·건전지, 라디오, 보조배터리의 구매 전 확인 항목을 배치했습니다. 현재 제휴 판매처·상품·광고·구매/결제 기능은 연결하지 않았습니다.

### 물품 제휴 수익화 제안 (미연동)

평상시 준비 영역에 판매처 연결을 두고, 초기에는 재고/결제를 직접 운영하기보다 제휴 판매처 링크부터 검토하는 방향입니다. 방문·구매 전환과 제휴 조건이 확인되기 전에는 수익을 예상하거나 보장하지 않습니다.

- 유료 노출은 카드 첫 부분에 `광고`, 구매 수수료가 있는 링크는 `제휴 링크 · 구매 시 수수료 발생 가능`을 표시하는 설계.
- 경보/대피/행동요령/지도 위에는 광고를 삽입하지 않으며, 핵심 기능 접근이나 대피소 정렬에 결제·광고 시청 조건을 두지 않음.
- 사용자 위치, 가족 약속, 경보 이용 기록을 광고 타기팅에 사용하지 않음. 현재 광고 SDK·추적·외부 상품 요청은 없음.
- 실제 연동 전 할 일: 제휴 판매처/조건 선정, 상품·가격·재고·배송·반품 정보 검증, 광고/수수료 표시와 외부 이동 UX 검토. 위장된 정부 추천, 근거 없는 보호 성능/안전 보장 표현은 사용하지 않음.

### 출시 전 점검 (2026-11-01)

**현재 공개 출시 준비 완료 상태는 아닙니다.** [출시 체크리스트](RELEASE_CHECKLIST.md)에 서명·식별자·정책·스토어 자료·실기기 검증과 근거를 기록했습니다. Android AAB와 iOS release 빌드는 미서명으로 검증했으며 스토어 업로드는 하지 않았습니다.

- 공습 등 긴급 행동은 빨강, 경계/주의는 주황, 일반 행동은 초록으로 구분하고 훈련 표시를 유지합니다.
- **나의 준비 → 데이터와 권한**에서 기기 저장·GPS·외부 지도·수동 공유·삭제 방법을 확인합니다. 공개 개인정보처리방침은 별도로 준비해야 합니다.
- 판매처가 없는 비상용품 미리보기는 debug에서만 보입니다. 릴리스의 기존 준비물 체크리스트와 라디오 연결은 유지합니다.
- 실제 정부 경보 수신·발송은 미구현이며 지도 배경은 온라인 기능입니다.

### iPhone PWA 개발 미리보기

`./scripts/build_pwa.sh` 후 `python3 -m http.server 8765 --bind 127.0.0.1 --directory build/web`를 실행하고 Mac에서 http://127.0.0.1:8765 를 엽니다. 처음에는 홈 화면 추가/오프라인 저장 안내가 나타나며 설치 없이 행동요령으로 이동할 수 있습니다. 설치 안내는 상단 **설치·오프라인**에서 다시 엽니다.

외부 배포는 하지 않았습니다. iPhone 실기기의 홈 화면 설치와 VoiceOver는 별도 검증이 필요합니다. [PWA 구현 범위](PWA_PLAN.md) · [서버 구성과 배포 조건](SERVER_PLAN.md).

PWA 첫 방문은 앱의 핵심 가치와 실제 화면을 보여주는 3단계 소개로 시작합니다. **먼저 둘러보기**로 건너뛰거나 마지막 단계에서 홈 화면 추가/오프라인 저장을 진행합니다. 이미 방문했다면 주소 끝에 `?intro=1`을 붙여 소개를 다시 볼 수 있습니다. 공개 배포에는 HTTPS 호스팅 서버가 필요하며, 현재 준비한 배포안은 Cloudflare Pages입니다. 외부 배포는 아직 하지 않았습니다.
